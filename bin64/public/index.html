Overwrite server.js?
This will replace the running server.js on disk and immediately restart Node.js.

The dashboard will go offline for a few seconds while it reboots. If your code has a syntax error, the server won't come back up until you fix it manually via start.bat.
Stop Web Server?
This will kill the Node.js server — which means this dashboard will go offline immediately.

You won't be able to access it until you run start.bat again on the server machine.
How to use
IP Whitelist
Adding an IP
Type any public IPv4 like 203.0.113.45 and click Add IP. Only whitelisted IPs can connect through the proxy. The proxy auto-restarts after changes.
Removing an IP
Click Remove next to any IP. Access revokes immediately and the proxy restarts. If it's not working, check the fix below.
What IP to enter?
Enter the public IP of whoever needs access. Check whatismyip.com. Don't use LAN IPs like 192.168.x.x — those won't work from the internet.
IP Remove Not Working?
Check whitelist.cfg format
The server looks for lines like allow * 1.2.3.4 in whitelist.cfg. If your file has a different format (just raw IPs), the remove function won't match. Use the Config Editor in Advanced to check and fix.
Status & Controls
Online / Offline badge
Pings the server every second. Offline means Node.js crashed or 3proxy isn't running — run start.bat.
Stop Web Server warning
Stopping the web server kills Node.js — the dashboard goes dark instantly. You must physically run start.bat on the server machine to bring it back.
