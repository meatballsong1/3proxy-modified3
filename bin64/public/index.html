How to use

Adding an IP: Type any public IPv4 like 203.0.113.45 and click Add IP. Only whitelisted IPs can connect through the proxy.

Removing an IP: Click Remove. If it doesn't work, check whitelist.cfg — the server expects lines like allow * 1.2.3.4.

Offline / Refusing: When a node doesn't respond to ping after multiple attempts it shows as "Offline — Refusing to respond". This means the node machine is unreachable on Tailscale or 3proxy is down.

Speed test ping: Averaged over 5 sequential pings to give a stable reading. A single outlier won't skew the result.
